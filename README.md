# 지금 제주 날씨는?

HTML, CSS, JavaScript로 만든 제주 현재 날씨 웹앱입니다.

## 실행

1. `index.html`을 브라우저로 엽니다.
2. https://www.weatherapi.com/my/ 에서 발급받은 API 키를 입력하고 **연결하기**를 누릅니다.
3. **새로고침**으로 최신 날씨를 다시 요청합니다.

**이 브라우저에 키 저장**을 선택하면 다음 방문 시 자동으로 날씨를 조회합니다. 기본값은 저장하지 않음이며, 저장하지 않은 키는 페이지를 닫으면 사라집니다. 저장 선택을 해제하면 저장된 키가 삭제됩니다.

## 데이터

- 요청: `https://api.weatherapi.com/v1/current.json`
- 위치: 제주시 좌표 `33.4996,126.5312` (제주도 전체의 평균값이 아닙니다.)
- 한국어: `lang=ko`
- 표시: `temp_c`, `humidity`, `condition.text`, `last_updated`
- 15초 요청 제한, 오류 안내, 요청 중 중복 클릭 방지
- 다시 불러오기에 실패하면 이전 데이터임을 명시합니다.

API 키가 제공되지 않았으므로 실제 날씨 조회에는 본인의 유효한 키가 필요합니다. 예시 날씨를 실제 관측값으로 표시하지 않습니다.

이 앱은 개인 학습용 프런트엔드입니다. 브라우저에서 직접 호출하므로 키는 개발자 도구에서 확인할 수 있습니다. 공개 서비스에 운영자 키를 포함하려면 서버 프록시와 서버 환경 변수로 전환하세요.

공식 문서: https://www.weatherapi.com/docs/
